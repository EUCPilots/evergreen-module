# Get-EvergreenAppsPath

## SYNOPSIS

Devuelve la ruta de la caché local de las funciones y los manifiestos de aplicaciones de Evergreen.

## SYNTAX

```
Get-EvergreenAppsPath
```

## DESCRIPTION

Devuelve la ruta de la caché local de las funciones y los manifiestos de aplicaciones de Evergreen.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-EvergreenAppsPath
```

Descripción:
Devuelve la ruta de la caché local de las funciones y los manifiestos de aplicaciones de Evergreen.

## OUTPUTS

### System.String
