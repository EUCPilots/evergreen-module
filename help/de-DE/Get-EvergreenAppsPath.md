# Get-EvergreenAppsPath

## SYNOPSIS

Gibt den lokalen Cachepfad der Evergreen-App-Funktionen und -Manifeste zurück.

## SYNTAX

```
Get-EvergreenAppsPath
```

## DESCRIPTION

Gibt den lokalen Cachepfad der Evergreen-App-Funktionen und -Manifeste zurück.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-EvergreenAppsPath
```

Beschreibung:
Gibt den lokalen Cachepfad der Evergreen-App-Funktionen und -Manifeste zurück.
