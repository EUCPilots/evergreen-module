# Get-EvergreenAppsPath

## SYNOPSIS

Renvoie le chemin d’accès au cache local des fonctions et manifestes des applications Evergreen.

## SYNTAX

```
Get-EvergreenAppsPath
```

## DESCRIPTION

Renvoie le chemin d’accès au cache local des fonctions et manifestes des applications Evergreen.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-EvergreenAppsPath
```

Description :
Renvoie le chemin d’accès au cache local des fonctions et manifestes des applications Evergreen.
