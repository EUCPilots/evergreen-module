# Get-EvergreenAppsPath

## SYNOPSIS

Evergreen アプリ関数とマニフェストのローカル キャッシュ パスを返します。

## SYNTAX

```
Get-EvergreenAppsPath
```

## DESCRIPTION

Evergreen アプリ関数とマニフェストのローカル キャッシュ パスを返します。

## EXAMPLES

### EXAMPLE 1

```powershell
Get-EvergreenAppsPath
```

説明：
Evergreen アプリ関数とマニフェストのローカル キャッシュ パスを返します。
