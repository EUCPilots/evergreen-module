# Evergreen

## about_Evergreen

### SHORT DESCRIPTION

一般的な Windows アプリケーションの最新バージョンとダウンロード URL を返します。

### LONG DESCRIPTION

Evergreen は、一般的な Windows アプリケーションの最新バージョンとダウンロード URL を返す PowerShell モジュールです。このモジュールには、次のようなさまざまなタスクを実行するスクリプトで使用できるシンプルな関数が含まれています：

- 特定のアプリケーションの最新バージョンを取得し、インストール済みまたはダウンロード済みのバージョンと比較する
- アプリケーションの最新バージョンの URL を取得し、ローカルへのインストールや対象コンピューターへの展開のためにダウンロードする

Evergreen は、ソフトウェアの展開を自動化するソリューションでの使用を想定しています。たとえば次のような用途があります：

- Hashicorp Packer によるイメージ作成 - 一連のアプリケーションの最新バージョンを含むイメージを作成できます
- Microsoft Endpoint Manager へのアプリケーションのインポート - Configuration Manager または Microsoft Intune をアプリケーションの最新バージョンに保つことができます
- アプリケーション インストーラーのライブラリ作成 - Evergreen 関数を定期的に実行することで、アプリケーションの現在のバージョンを取得およびダウンロードし、後で使用できるようアプリケーション ディレクトリ構造に保存できます
- `Winget`、`Chocolatey` などへのマニフェストの登録 - Evergreen はバージョン番号とダウンロード URL を含むオブジェクトを返すことができ、最新バージョン用のマニフェスト作成に使用できます

Evergreen の主な関数：

- `Get-EvergreenApp` - バージョン番号とダウンロード URL など、アプリケーションの最新リリースの詳細を返します
- `Save-EvergreenApp` - `Get-EvergreenApp` が返すアプリケーション URL のダウンロードを簡単にします
- `Find-EvergreenApp` - モジュールでサポートされるアプリケーションを一覧表示します
